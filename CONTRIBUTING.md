# Contributing to NSA WSU Website

Thank you for your interest in contributing.

## Workflow

1. Fork this repository.
2. Create a new branch:

   git checkout -b feature/your-feature-name

3. Make your changes.
4. Test the website locally.
5. Commit your changes with a clear message.
6. Push your branch to your fork.
7. Open a pull request against the `main` branch.

## Important

- Do not submit changes directly to `main`.
- Keep each pull request focused on one feature or fix.
- Include screenshots for visual changes.
- Make sure the website remains responsive.
- Do not upload private student information or copyrighted images without permission.

> **Note:** All contributions must be submitted through a Pull Request. Direct pushes to the `main` branch are not permitted.
